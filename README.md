



# Too Fancy Textarea

A textarea that takes itself too seriously. Keystrokes strike sparks, deleted text burns out and smokes, and the cursor stretches as it travels.

The effects are inspired by the [Hyperpower](https://hyper.is/store/hyperpower) plugin for Hyper, but better.

https://github.com/user-attachments/assets/59a3502b-aa41-4e41-aaab-56aace12e4e2

## Run

Open `index.html` in a browser. No build step, no dependencies.

## How it works

A transparent `<textarea>` captures keyboard, IME and clipboard input. The text, cursor and particles are drawn on a `<canvas>`.

Supports word wrap, mouse and touch selection (double-click a word, triple-click a paragraph), cut/copy/paste, undo/redo, the usual macOS and Windows editing shortcuts, IME input, light and dark themes, and `prefers-reduced-motion`.
